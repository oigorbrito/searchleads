# SearchLeads Domain Foundation

Implementation of work unit `LEADS_SCIENTIFIC_FOUNDATION_AND_DOMAIN_V1` from the supplied B2B lead discovery/enrichment handoff.

This repository currently contains only the V1 scientific/domain foundation and tests. It intentionally stops before persistence, real-source acquisition, normalization algorithms, entity-resolution scoring, contact validation, qualification scoring, exports, scheduling, or any universal framework.

## Run tests

```bash
python -m unittest discover -s tests -v
```
